# 小説家になろう EPUB作成ツール (syosetu-epub-maker)

本プロジェクトは、「小説家になろう」（[https://syosetu.com](https://syosetu.com)）で公開されているWeb小説をスクレイピング（巡回クローリング）し、日本語の表示特性（縦書き、ルビ、段落インデントなど）を適切に保ちながら、厳格なEPUB 3形式の電子書籍（`.epub`）を自動生成するPythonベースのコマンドラインツール（CLI）です。

GitHub Codespaces環境に最適化されており、容易に起動、パッケージング、およびテストを行うことができます。

---

## 🌟 主な機能

1. **目次情報の多重クローリングと解析 (`scraper.py`)**
   - 小説のタイトル、作者名、前書き（あらすじ）を自動的に抽出。
   - 複数ページに分割された目次（ページネーション）にも自動で追従して全エピソードの情報を集約。
   - Nコードのみ（例：`n9636x`）、または完全なURLを入力として受け取ることができます。
   - ネットワークエラー等のリトライ機能（指数バックオフ付き）を搭載。

2. **サーバーに優しい巡回クローリング (`scraper.py`)**
   - ターゲットサーバーに過度な負荷をかけないよう、リクエスト間に必ず1秒（または任意設定値）のディレイを挿入。

3. **ルビや段落構造を維持するHTMLクレンジング (`converter.py`)**
   - 不要なナビゲーション、スクリプト、広告、外部スタイル、不要なHTML属性などを自動で除去。
   - 小説家になろう特有のルビタグ（`<ruby>`, `<rt>`）や段落（`<p>`）は完全に保持します。

4. **縦書き対応のEPUB 3パッケージビルド (`epub_builder.py`)**
   - 電子書籍標準仕様である EPUB 3 に厳格に準拠。
   - `mimetype`（非圧縮）、`META-INF/container.xml`、`content.opf`、ナビゲーション用の `nav.xhtml`、EPUB2互換用の `toc.ncx` を自動生成。
   - 縦書き（`writing-mode: vertical-rl`）用のCSS（`style.css`）が埋め込まれており、電子書籍リーダーでの表示に最適化されています。

5. **テスト/オフライン環境での柔軟な動作**
   - ネットワークが使えないオフライン環境でのユニットテストのために、`sample/` フォルダの目次（`目次.html`）やエピソード（`1.html`）などのローカルHTMLファイルをソースとして、スクレイピングからビルドまで一貫して動作させることができます。

## 🛠️ 環境構築・インストール

### 動作環境
- Python 3.8 以上（Python 3.12系でも動作確認済み）

### 依存パッケージのインストール
リポジトリのルートディレクトリで以下のコマンドを実行してください：

```bash
pip install -r requirements.txt
```

主要な依存ライブラリ：
- `requests`: WebサーバーからのHTML取得用
- `beautifulsoup4`: HTML/XMLパーサー
- `lxml`: 高速で強力なXML/HTMLパース、XHTML妥当性の保証
- `pytest`: 自動ユニットテスト用

## 🚀 使い方（CLI）

`main.py` は、以下の引数を取ります。
```bash
python main.py [対象URL / Nコード / 目次HTMLファイルパス] [出力EPUBパス (省略時は output.epub)]
```

### 1. Nコードを指定して作成
```bash
python main.py n9636x
```
*※ `ncode.syosetu.com/n9636x/` からスクレイピングし、デフォルトの `output.epub` を作成します。*

### 2. URLを指定して、出力ファイルを指定して作成
```bash
python main.py https://ncode.syosetu.com/n9636x/ my_novel.epub
```

### 3. ローカルのサンプルHTML（オフライン）から作成
インターネットに接続していない状態や、動作テストとしてローカルサンプルを使いたい場合に有効です。
```bash
python main.py sample/目次.html my_novel_sample.epub
```
*※ローカルファイルを指定した場合は、不要な通信待ちが発生しないようにリクエスト間のウェイト（delay）は自動的に 0秒 に設定されます。*

## 🧪 テストの実行

本プロジェクトには、ネットワーク状態、パース失敗、EPUBビルド時の各構成要素の検証など、豊富なテストコードが用意されています。
テストを実行するには、以下のコマンドをルートディレクトリで実行します：

```bash
python3 -m pytest
```

## 📝 開発ガイドライン (AGENTS.md)
本プロジェクトの開発にあたっては、以下のガイドライン（`AGENTS.md`）が定義されています：
1. 作業中のユーザーへの報告は必ず**日本語**で行う。
2. プルリクエストのコメントは**日本語**で作成する。
3. プログラム内には詳細な**日本語のコメント**を入れ、モジュールおよび関数のヘッダーコメントを日本語で記述する。
4. 外部のサービスに依存したコードを変更する際は、常に最新の公式ドキュメントを確認する。
